How It Works

Pipeline + Rule-Trace Overlay

1
Parse BUFR

Decode binary radiosonde data into a pressure-level DataFrame using eccodes.

2
Clean Profile

Remove sentinel values (−9999, 2e20) and sort levels surface → top.

3
Burst Detection

Apply WMO 30 hPa ceiling threshold to classify as premature or nominal.

4
Feature Engineering

Compute shear, Richardson number, icing/moisture indices, ascent-rate stats and tropopause stats — same 27 features used to train the v2 model.

5
Load Saved v2 Model

Load the pre-trained RandomForest, scaler, label encoder and CALIB percentile table from classifier/models/ — no retraining at inference time.

6
Predict, Trace & Validate

Scale features, run ML inference, and separately replay the percentile-rank labelling rules (RH, shear, ascent rate, etc.) for a transparent side-by-side comparison.
